# MASC_LAB_LIB
This is a library of MASC (Multi Agent System Control) Laboratory that contains some RESEARCH PAPER and SIMULATION FILE of each. That is contributed by all of the members in LAB.

### Feature Branch Rule

Every new feature MUST be developed on its own branch:

git checkout main

git pull origin main

git checkout -b feature/feature-name

# ... code ...
git push -u origin feature/feature-name

Then open a Pull Request targeting 'main'

**Rule: ** 1 feature = 1 branch = 1 Pull Request
